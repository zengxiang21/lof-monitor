指标说明与使用技巧
T-1净值=最近一个已公布净值（全市场最新为 —）； 跨境/QDII 基金净值通常滞后 1–2 天（源站未公布即沿用上一净值）； 滞后N天=源站仍有更新空间，停更=长期未披露（已清盘/停止运作）。 份额Δ=场内份额较上一交易日变动（收盘后更新）：份额激增=套利资金正在涌入，比溢价率更领先（深市深交所、沪市上交所）。 日限额=单日累计购买上限（天天基金交易页，每日 9:10/15:10 刷新；不限=无上限）。限额突涨/突降往往是套利窗口开关，异动见 /api/limits/changes。 估算净值已按 β 校准（每日 22:45 用官方净值回归校准系数，样本≥5 天启用个体 β，否则组级兜底；展开行可见 β 与近期误差）。 点击表头可按该列排序，再点一次切换升/降序（自动记住上次选择）。 点击行首 ☆ 加入自选关注（仅存本机浏览器，不参与推送），关注行高亮，顶部"☆ 关注"chip 可筛选。 右上角 🌙 切换暗色模式。信号战绩卡展示每日精选的 T+2 真实盈亏回填。 精选卡本金框可手动输入投资额（支持 1w=1万 / 1k=1千），实时算出预计净赚并记住。 表格卡右上角搜索框可按代码/名称即时过滤（与分类/关注/五关叠加）； 「⚠ 限额异动」chip一键筛出日限额突涨/突降（|变动|≥20%）的标的——限额异动往往是套利窗口开关； 「表格/卡片」切换视图（手机端默认卡片，选择会被记住）。
